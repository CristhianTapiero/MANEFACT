# MANEFACT
Manefact es un proyecto creado por Cristhian David Tapiero Padilla para las materias de Gestión de Proyectos y Arquitectura de la Información, con el fin de dr cumplimento al PENSUM de la carrera de Ingeniería de Sistemas de la Universidad Libre de Colombia. En esta página podrá visualizar datos básicos del proyecto y realizar pre-registro con el fin de hacer un estudio de posible aceptación del proyecto.
